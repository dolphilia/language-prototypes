# Aya（あや）0.1

[リポジトリの目次へ](../../README.md) · [試作言語の一覧へ](../README.md) · [調査メモ](../../docs/notes/README.md)

**所有する値を基本とし、共有には明示的な権限を、外部接続には明示的な契約を使う言語の仕様案です。**

状態: **設計草案。処理系は未実装。** 作成日: **2026-11-07**。

仮称のAyaは、複数の設計を組み合わせる「綾」から取っています。既存言語との互換性や名称の独占は意図しません。Taneとは別の試作です。

- [言語仕様書](spec.md): 構文、値と資源、所有と借用、モード、共有領域、効果、並行処理、外部契約、受理・拒否の規則。
- [設計判断と検証計画](design.md): 採用した考え方、採用範囲を絞った理由、安全性の証明義務、実装の順序。

通常は可変値意味論で書き、循環グラフなどが必要な部分だけ、ブランド付き領域と権限キーを使います。局所性・クロージャの利用回数・タスクへの移譲を別々に検査します。任意の内部検査を外すunsafeブロックは設けず、未検証の外部契約を引き受ける宣言を接続設定に限定します。

掲載コードは、仕様を説明するAyaのプログラムです。Rust・Hylo・OCamlのコードではなく、コンパイル・実行はまだできません。仕様が定める保証と、実装や形式証明によって保証を確立できた状態を区別します。
